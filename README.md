# 补给光柱 Supply Beam

> Minecraft Java **26.2** ｜ NeoForge **26.2** ｜ 与 [猎人游戏 Manhunt](https://github.com/TakaraMiyuki/Manhunt) 可选联动
> 作者：TakaraMiyuki ｜ 许可：MIT

灵感来自《方舟：生存飞升》的空投光柱补给：主世界会随机刷新**彩色补给光柱**，光柱颜色决定稀有度——稀有度越高，开出的物资越好。光柱自地面缓缓显现后，一枚**菱形八面体补给箱**会沿光柱从天空缓慢降落；着陆后即可右键拾取，若长时间无人拾取，补给箱将自行消散。

## 1. 玩法一览

| 项目 | 规则 |
| --- | --- |
| 刷新范围 | 仅主世界；距随机在线玩家 24–64 格的地表（干燥实心地面，排除海面/湖面/树冠） |
| 并发上限 | 同一世界同时最多 3 根光柱 |
| 刷新节奏 | 每 2–4 分钟尝试一次 |
| 出现提示 | 光柱出现时，128 格内玩家收到快捷栏提示（按稀有度着色），并伴随低沉的信标启动音 |
| 可见距离 | 实体同步距离 256 格，远处也能望见光柱 |
| 拾取方式 | 补给箱着陆后**右键**拾取，战利品撒落在箱体周围（先到先得） |
| 消失规则 | 着陆后 **5 分钟**无人拾取即消散；消散前有 2 秒缩小动画与音效提示 |

## 2. 稀有度与奖池

参照方舟的空投颜色梯度，五档稀有度按权重随机：

| 档位 | 颜色 | 权重 | 条数 | 定位 |
| --- | --- | --- | --- | --- |
| 常规补给 | 🟢 绿 | 46 | 4 | 食物、火把、铁锭、箭等生存基础物资 |
| 稀有补给 | 🔵 蓝 | 27 | 6 | 金锭、铁甲、弓盾、黑曜石、TNT 等成型资源 |
| 史诗补给 | 🟣 紫 | 15 | 8 | 钻石、金苹果、附魔书、附魔铁装、末影珍珠 |
| 传说补给 | 🔴 红 | 9 | 10 | 合金碎片、图腾、附魔金苹果、附魔钻装、三叉戟 |
| 神话补给 | 🟡 金 | 3 | 12 | **低概率鞘翅**、合金锭、信标、潜影盒、锻造模板、附魔合金装 |

- 奖池为代码化定义（`SupplyLoot.java`），物品与权重直接改常量即可。
- 神话档的鞘翅与 Manhunt 四档里程奖池的"低概率鞘翅"定位互补，不冲突。
- 附魔装备/附魔书由活动注册表随机抽取，等级受档位上限约束。

## 3. 完整流程与计时

```
光柱出现（低鸣+提示）
   │  显现阶段 20 秒：光柱自地面"生长"至顶端（easeOut 缓动），根部尘埃聚集
   ▼
补给箱现身于光柱顶端（发射音效）
   │  降落阶段：0.6 格/秒缓降（42–56 格落差约 70–93 秒），尾迹粒子 + 缓速自转
   ▼
着陆（闷响 + 尘环爆开）
   │  待拾取 5 分钟：悬浮呼吸 + 光环脉动 + 稀有度色尘埃环
   │  玩家右键 → 战利品撒落，光柱与箱体一同消散
   ▼  超时无人拾取
消散（缩小 2 秒 + 消散音 + 粒子）
```

## 4. 与 Manhunt 的联动

本模组是 **Manhunt 家族的兼容附属**，与主模组相互独立、可单独使用：

- 安装 Manhunt 后：**逃脱窗口期**（猎人被定身热身的 60 秒）自动暂停刷新光柱，追逐阶段照常刷新——空投成为双方争夺的地图资源点。
- 未安装 Manhunt：作为独立玩法在任何存档运行。
- 依赖声明为可选（`optional`，ordering `NONE`），不存在加载顺序约束。

## 5. 管理员指令

需要权限等级 2（OP）：

| 指令 | 说明 |
| --- | --- |
| `/supplybeam spawn <rarity>` | 在准星所指位置强制生成一根光柱；`rarity` ∈ common/uncommon/rare/epic/mythic（Tab 补全） |
| `/supplybeam clear` | 清除当前维度的全部补给光柱 |

## 6. 可调数值

全部数值集中在 `SupplyBeamConfig.java`（常量，改后重编译）：

| 常量 | 默认值 | 说明 |
| --- | --- | --- |
| `SPAWN_INTERVAL_MIN/MAX_TICKS` | 2400 / 4800 | 刷新间隔区间（刻） |
| `MAX_ACTIVE` | 3 | 单世界光柱上限 |
| `SPAWN_RADIUS_MIN/MAX` | 24 / 64 | 距玩家刷新距离（格） |
| `BEAM_HEIGHT_MIN/MAX` | 42 / 56 | 光柱顶端落差（格） |
| `BEAM_GROWTH_TICKS` | 400 | 显现阶段时长（20 秒） |
| `DESCEND_SPEED` | 0.03 | 降落速度（格/刻，即 0.6 格/秒） |
| `GROUND_LIFETIME_TICKS` | 6000 | 着陆后待拾取时长（5 分钟） |
| `VANISH_TICKS` | 40 | 消散动画时长（2 秒） |

稀有度权重/颜色/条数在 `SupplyRarity` 枚举中；奖池在 `SupplyLoot`。

## 7. 安装与构建

```
# 构建（需要 JDK 25）
./gradlew build
# 产物：build/libs/supplybeam-<版本>.jar
```

- 客户端与服务端都需要安装（单人内置服务端同理）。
- 与 Manhunt / SkillCards / Flying 同族模组共存无冲突；本模组不依赖 Curios。

## 8. 美术资产

- 所有贴图由 `tools/make_textures.py`（Python + PIL，4× 超采样）程序化生成，可一键重生成或直接替换 PNG。
- `blockbench/supply_crate.bbmodel` 为补给箱的 Blockbench 工程（已内嵌贴图），可直接打开编辑八面体网格与 UV。
- 视觉元素：双层十字光柱（信标管线全亮渲染）、脉动地面光环、逐面平板着色的八面体金属外壳、中央窗格透出的脉冲光核——夜间尤其醒目。
