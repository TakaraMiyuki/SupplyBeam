# 补给光柱 Supply Beam

> Minecraft Java **26.2** ｜ NeoForge **26.2** ｜ 与 [猎人游戏 Manhunt](https://github.com/TakaraMiyuki/Manhunt) 可选联动
> 作者：TakaraMiyuki ｜ 许可：MIT

灵感来自《方舟：生存飞升》的空投光柱补给：主世界的**远方向**会随机刷新**彩色补给光柱**，光柱自天空**向下延伸**显现；随后一枚 **3 格高的菱形八面体补给箱**从光柱正中间沿光柱缓慢降落，可以降落在平地、树冠顶、屋顶、雪地甚至**水面**（浮在水面不下沉）。着陆后右键开启：独立运行时直接掉落补给品；与 Manhunt 联动时则触发对应档位的**资源抽奖**。名牌实时显示消散倒计时，超时无人拾取将消散（光柱自下而上收回）。

## 1. 玩法一览

| 项目 | 规则 |
| --- | --- |
| 刷新范围 | 仅主世界；距随机在线玩家 **96–384 格**（可配置）——光柱出现在视野地平线与已探索区域之间，**玩家看到（或收到提示）后主动前往** |
| 可降落表面 | 平地、**树冠顶**、**屋顶**、**雪地**、**水面**（补给箱悬浮在表面，不下沉）；仅拒绝岩浆 |
| 并发上限 | 同一世界同时最多 3 根光柱（可配置） |
| 刷新节奏 | 每 2–4 分钟尝试一次（可配置） |
| 发现方式 | 默认开启**刷新文字提示**（全服聊天，含坐标，可配置关闭）；关闭提示后需要自己留意地平线上的彩色光柱 |
| 拾取方式 | 补给箱着陆后**右键**开启（先到先得）；联动模式触发抽奖动画，独立模式撒落物品 |
| 名牌规则 | 降落途中隐匿；**完全落地后**显示"史诗 · 空投补给箱（m:ss后消散）"，每秒刷新 |
| 消失规则 | 着陆后 **5 分钟**（可配置）无人拾取即消散；光柱自下而上收回，箱体同步缩小 |
| 持久化 | 补给箱随存档保存：远离玩家时进度冻结，回到加载范围后从原进度继续，重启服务器不丢失 |

## 2. 稀有度与奖池

四档稀有度（默认权重可在配置调整）：

| 档位 | 默认颜色 | 默认权重 | Manhunt 联动 | 独立模式奖池 |
| --- | --- | --- | --- | --- |
| 罕见补给 | 🟢 `#3AE86B` | 46 | 一档奖池 | 食物、火把、铁锭、箭等生存基础物资 |
| 稀有补给 | 🔵 `#3AB8FF` | 27 | 二档奖池 | 金锭、铁甲、弓盾、黑曜石、TNT 等成型资源 |
| 史诗补给 | 🟣 `#B45BFF` | 18 | 三档奖池 | 钻石、金苹果、附魔书、附魔铁装、末影珍珠 |
| 传奇补给 | 🔴 `#FF4A5E` | 9 | 四档奖池 | 合金、图腾、附魔金苹果、附魔钻装、三叉戟；低概率鞘翅/信标/潜影盒 |

- **安装 Manhunt 时**：四档稀有度直接对应 Manhunt 资源抽奖的**四档里程奖池**（数据同源，跟随 Manhunt 更新）。
- **独立运行时**：使用自带奖池（`SupplyLoot.java`，物品与权重可改）。
- 光柱颜色由**服务端**下发并同步到客户端渲染，多人时以服务端配置为准。

## 3. 完整流程与计时

```
光柱出现（自天空向下延伸至地面，20 秒 easeOut；触地时光环亮起）
   │  无提示时可配置开启文字提示（默认开，含坐标）
   ▼
补给箱现身于光柱正中间（发射音效，附近可闻）
   │  降落阶段：0.6 格/秒（可配置）沿光柱缓降，尾迹粒子 + 缓速自转
   ▼
着陆（闷响 + 尘环爆开，附近可闻）——平地/树冠顶/屋顶/雪地/水面
   │  名牌亮出："史诗 · 空投补给箱（4:32后消散）"，每秒刷新
   │  玩家右键 → 联动模式：对应档位资源抽奖（老虎机动画+待领取）
   │             独立模式：战利品撒落，光柱与箱体一同消散
   ▼  超时无人拾取
消散（光柱自下而上收回 2 秒 + 消散音 + 粒子）
```

## 4. 与 Manhunt 的联动

本模组是 **Manhunt 家族的兼容附属**，与主模组相互独立、可单独使用：

- **奖池联动**：检测到 Manhunt 时，右键补给箱不再直接掉落物品，而是**触发一次对应档位的资源抽奖**——四档稀有度对应 Manhunt 四档里程奖池，复用其老虎机动画与待领取交互（上下方向键领取）。
- **节奏联动**：逃脱窗口期（猎人被定身热身的 60 秒）自动暂停刷新光柱，追逐阶段照常刷新——空投成为双方争夺的地图资源点。
- 未安装 Manhunt：作为独立玩法运行（开箱掉落自带奖池物资）。
- 依赖声明为可选（`optional`，ordering `NONE`），不存在加载顺序约束。

## 5. 游戏内配置

配置文件 `config/supplybeam-common.toml`（首次启动生成），支持三种修改方式：

**① 图形配置界面（推荐，单人）**：模组列表（mods 菜单）→ 选中"补给光柱" → 点"配置"按钮。三页分页（刷新 / 光柱与补给箱 / 稀有度与颜色），颜色项带实时色块预览，保存时逐项校验，非法值红字提示且不写入。

**② 指令配置（推荐，服务器，权限等级 2，立即生效并写入文件）**：

```
/supplybeam config list              列出全部配置项与当前值
/supplybeam config set <key> <value> 热更新（如 set crate.groundLifetimeSeconds 60、set rarity.colorEpic #B45BFF）
/supplybeam config reset <key>       恢复某项默认值
/supplybeam info                     查看活跃光柱数、下次刷新倒计时、调试开关
```

**③ 直接改 TOML 文件**：重启后生效（指令与 GUI 改动即时落盘，无需重启）。

| 分节 | 配置项 | 默认值 | 说明 |
| --- | --- | --- | --- |
| spawn | `spawnIntervalMinSeconds` / `Max` | 120 / 240 | 刷新尝试间隔区间（秒） |
| spawn | `maxActive` | 3 | 单世界光柱上限 |
| spawn | `spawnRadiusMin` / `Max` | 96 / 384 | 距随机玩家的生成距离（格） |
| spawn | `minSurfaceY` | 63 | 低于该地表高度不生成 |
| spawn | `noticeEnabled` | true | 光柱自然刷新时向全服发送带坐标的文字提示 |
| beam | `beamHeightMin` / `Max` | 126 / 168 | 光柱顶端距地表高度（格） |
| beam | `beamGrowthSeconds` | 20 | 光柱生长时长（秒） |
| crate | `descendSpeedBlocksPerSecond` | 0.6 | 补给箱下降速度（格/秒） |
| crate | `groundLifetimeSeconds` | 300 | 着陆后待拾取时长（秒） |
| rarity | `weightUncommon` / `Rare` / `Epic` / `Legendary` | 46/27/18/9 | 各稀有度刷新权重 |
| rarity | `colorUncommon` / `Rare` / `Epic` / `Legendary` | 见上表 | 各稀有度光柱颜色（#RRGGBB） |
| debug | `debugMode` | false | 调试模式开关（见下节） |

> 光柱颜色在服务端修改后对所有玩家生效（颜色随实体同步）；其余行为项仅服务端需要一致。

## 6. 调试模式

`/supplybeam debug on` 开启（关闭用 `off`），开关本身会写入配置文件持久保存。开启后解锁：

| 指令 | 说明 |
| --- | --- |
| `/supplybeam spawn <rarity>` | 在准星所指位置强制生成一根光柱（无需调试模式）；`rarity` ∈ uncommon/rare/epic/legendary |
| `/supplybeam clear` | 清除当前维度全部光柱（无需调试模式） |
| `/supplybeam spawnhere <rarity>` | 在脚下生成光柱 |
| `/supplybeam list` | 列出当前维度光柱明细：坐标、稀有度、阶段、剩余时间 |
| `/supplybeam fastforward` | 准星光柱直接跳到下一阶段（显现→降落→着陆→消散各瞬间完成） |
| `/supplybeam timer <seconds>` | 设置准星光柱的消散倒计时 |

调试模式开启时还会：自然刷新成功后**向全服广播坐标**（`[调试] 传奇补给 光柱已刷新于 x=…, z=…`）；控制台记录每次刷新尝试的选址/跳过原因，排查"为什么没刷"一目了然。

> "准星光柱"的判定：优先取视线方向夹角最小的光柱，否则回退为 24 格内最近的光柱。
>
> **选址说明**：光柱可降落在树冠顶、屋顶、雪地、水面（补给箱悬浮在表面），仅拒绝岩浆；每次尝试会在目标点附近随机回退搜索 15 次；`spawn`/`spawnhere` 失败时会给出具体原因。

## 7. 安装与构建

```
# 构建（需要 JDK 25）
./gradlew build
# 产物：build/libs/supplybeam-<版本>.jar
```

- 客户端与服务端都需要安装（单人内置服务端同理）。
- 与 Manhunt / SkillCards / Flying 同族模组共存无冲突；本模组不依赖 Curios。

## 8. 美术资产

- 所有贴图由 `tools/make_textures.py`（Python + PIL，4× 超采样）程序化生成，可一键重生成或直接替换 PNG。
- `blockbench/supply_crate.bbmodel` 为补给箱的 Blockbench 工程（已内嵌 128×128 贴图，3 格高八面体网格），可直接打开编辑。
- 视觉元素：双层十字光柱（信标管线全亮渲染、**自上而下显现/自下而上消散**）、脉动地面光环、**全亮自发光**的八面体金属外壳（夜晚不再隐没）、中央窗格透出的脉冲光核。
