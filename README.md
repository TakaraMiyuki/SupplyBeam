# 补给光柱 Supply Beam

> Minecraft Java **26.2** ｜ NeoForge **26.2** ｜ 与 [猎人游戏 Manhunt](https://github.com/TakaraMiyuki/Manhunt) 可选联动
> 作者：TakaraMiyuki ｜ 许可：MIT

灵感来自《方舟：生存飞升》的空投光柱补给：主世界的**远方向**会随机刷新**彩色补给光柱**，光柱颜色决定稀有度——稀有度越高，开出的物资越好。光柱自地面缓缓显现后，一枚 **3 格高的菱形八面体补给箱**从光柱正中间沿光柱缓慢降落；着陆后即可右键拾取，名牌实时显示消散倒计时，超时无人拾取将自行消散。

## 1. 玩法一览

| 项目 | 规则 |
| --- | --- |
| 刷新范围 | 仅主世界；距随机在线玩家 **96–384 格**（可配置）——光柱出现在视野地平线与已探索区域之间，**玩家看到后需要主动前往** |
| 并发上限 | 同一世界同时最多 3 根光柱（可配置） |
| 刷新节奏 | 每 2–4 分钟尝试一次（可配置） |
| 发现方式 | **无任何提示**——留意地平线上的彩色光柱；光柱高逾百格、夜间极远可见 |
| 拾取方式 | 补给箱着陆后**右键**拾取，战利品撒落在箱体周围（先到先得） |
| 名牌规则 | 降落途中隐匿；**完全落地后**显示"稀有度 · 空投补给箱（m:ss后消散）"，每秒刷新 |
| 消失规则 | 着陆后 **5 分钟**（可配置）无人拾取即消散；消散前有 2 秒缩小动画与音效提示 |
| 持久化 | 补给箱随存档保存：远离玩家时进度冻结，回到加载范围后从原进度继续，重启服务器不丢失 |

## 2. 稀有度与奖池

参照方舟的空投颜色梯度，五档稀有度按配置权重随机：

| 档位 | 默认颜色 | 默认权重 | 条数 | 定位 |
| --- | --- | --- | --- | --- |
| 常规补给 | 🟢 `#3AE86B` | 46 | 4 | 食物、火把、铁锭、箭等生存基础物资 |
| 稀有补给 | 🔵 `#3AB8FF` | 27 | 6 | 金锭、铁甲、弓盾、黑曜石、TNT 等成型资源 |
| 史诗补给 | 🟣 `#B45BFF` | 15 | 8 | 钻石、金苹果、附魔书、附魔铁装、末影珍珠 |
| 传说补给 | 🔴 `#FF4A5E` | 9 | 10 | 合金碎片、图腾、附魔金苹果、附魔钻装、三叉戟 |
| 神话补给 | 🟡 `#FFC845` | 3 | 12 | **低概率鞘翅**、合金锭、信标、潜影盒、锻造模板、附魔合金装 |

- 权重与光柱颜色均在配置文件中调整；奖池物品与权重在 `SupplyLoot.java`。
- 神话档的鞘翅与 Manhunt 四档里程奖池的"低概率鞘翅"定位互补，不冲突。
- 附魔装备/附魔书由活动注册表随机抽取，等级受档位上限约束。
- 光柱颜色由**服务端**下发并同步到客户端渲染，多人时以服务端配置为准。

## 3. 完整流程与计时

```
光柱出现（无提示，静静立在远方）
   │  显现阶段 20 秒（可配置）：光柱自地面"生长"至逾百格高空（easeOut 缓动）
   ▼
补给箱现身于光柱正中间（发射音效，附近可闻）
   │  降落阶段：0.6 格/秒（可配置）沿光柱缓降，尾迹粒子 + 缓速自转
   ▼
着陆（闷响 + 尘环爆开，附近可闻）
   │  名牌亮出："史诗 · 空投补给箱（4:32后消散）"，每秒刷新
   │  玩家右键 → 战利品撒落，光柱与箱体一同消散
   ▼  超时无人拾取
消散（缩小 2 秒 + 消散音 + 粒子）
```

## 4. 与 Manhunt 的联动

本模组是 **Manhunt 家族的兼容附属**，与主模组相互独立、可单独使用：

- 安装 Manhunt 后：**逃脱窗口期**（猎人被定身热身的 60 秒）自动暂停刷新光柱，追逐阶段照常刷新——空投成为双方争夺的地图资源点。
- 未安装 Manhunt：作为独立玩法在任何存档运行。
- 依赖声明为可选（`optional`，ordering `NONE`），不存在加载顺序约束。

## 5. 配置文件

首次启动生成 `config/supplybeam-common.toml`（单人/服务端各自加载），全部数值热注释齐全：

| 分节 | 配置项 | 默认值 | 说明 |
| --- | --- | --- | --- |
| spawn | `spawnIntervalMinSeconds` / `Max` | 120 / 240 | 刷新尝试间隔区间（秒） |
| spawn | `maxActive` | 3 | 单世界光柱上限 |
| spawn | `spawnRadiusMin` / `Max` | 96 / 384 | 距随机玩家的生成距离（格） |
| spawn | `minSurfaceY` | 63 | 低于该地表高度不生成 |
| beam | `beamHeightMin` / `Max` | 126 / 168 | 光柱顶端距地表高度（格） |
| beam | `beamGrowthSeconds` | 20 | 光柱生长时长（秒） |
| crate | `descendSpeedBlocksPerSecond` | 0.6 | 补给箱下降速度（格/秒） |
| crate | `groundLifetimeSeconds` | 300 | 着陆后待拾取时长（秒） |
| rarity | `weightCommon` … `weightMythic` | 46/27/15/9/3 | 各稀有度刷新权重 |
| rarity | `colorCommon` … `colorMythic` | 见上表 | 各稀有度光柱颜色（#RRGGBB） |

> 光柱颜色在服务端修改后对所有玩家生效（颜色随实体同步）；其余行为项仅服务端需要一致。

## 6. 管理员指令

需要权限等级 2（OP）：

| 指令 | 说明 |
| --- | --- |
| `/supplybeam spawn <rarity>` | 在准星所指位置强制生成一根光柱；`rarity` ∈ common/uncommon/rare/epic/mythic（Tab 补全） |
| `/supplybeam clear` | 清除当前维度的全部补给光柱 |

## 7. 安装与构建

```
# 构建（需要 JDK 25）
./gradlew build
# 产物：build/libs/supplybeam-<版本>.jar
```

- 客户端与服务端都需要安装（单人内置服务端同理）。
- 与 Manhunt / SkillCards / Flying 同族模组共存无冲突；本模组不依赖 Curios。

## 8. 美术资产

- 所有贴图由 `tools/make_textures.py`（Python + PIL，4× 超采样）程序化生成，可一键重生成或直接替换 PNG。
- `blockbench/supply_crate.bbmodel` 为补给箱的 Blockbench 工程（已内嵌 128×128 贴图，3 格高八面体网格），可直接打开编辑。
- 视觉元素：双层十字光柱（信标管线全亮渲染）、脉动地面光环、**全亮自发光**的八面体金属外壳（夜晚不再隐没）、中央窗格透出的脉冲光核。
